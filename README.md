# Vortex One

Real full-stack owner intelligence, CRM, dialer, campaigns, templates, and agent operations platform.

## Status

Initial production foundation.

## Run

1. Copy `.env.example` to `.env`.
2. Set `DATABASE_URL` and `JWT_SECRET`.
3. Run `npm install`.
4. Run `npm run db:migrate`.
5. Run `npm run dev`.

For production: `npm run build` then `npm start`.
